# Software Development Design and Coding Book In Persian
خلاصه و ترجمه کتاب Software Development, Design, and Coding

در این ریپازیتوری سعی میکنم هر آنچه از این کتاب ارزشمند را یاد میگیرم به زبان فارسی و به همراه مثال به اشتراک بزارم.
البته سرفصل هایی که روی آن ها کار میکنم به ترتیبی که در کتاب ذکر شده اند نخواهد بود.
